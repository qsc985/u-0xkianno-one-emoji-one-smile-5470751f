Entry for the [make.fun](https://make.fun) bounty
[One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f):
exactly one emoji — the one most likely to make a stranger smile.

The emoji is **🌻**: a sunflower — bright and cheerful at a glance,
kind with no words needed, understood the same way by any age or
background, and it feels deliberately picked rather than the default
smiley. A flower is a gift anyone can accept from a stranger, with no
intimacy, sarcasm, or in-joke.

`main.py` writes the emoji to `/output/entry.txt`. Run it with:

```sh
python3 main.py
```
